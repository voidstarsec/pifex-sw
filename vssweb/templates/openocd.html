OpenOCD: Arguments

  • OpenOCD can be run with a specified config file:
    • openocd -f file.cfg
  • Individual commands can also be passed with the -c option
    • openocd -c "reset halt"
  • Predefined scripts in /usr/local/share/openocd/scripts/ can also be provided
    • openocd -f target/allwinner_v3s.cfg
  • Arguments are run in the order they are provided!

OpenOCD: Config Files

  • A core component of OpenOCD is the config files used for various targets
    • Located at /usr/local/share/scripts
  • The config files define every parameter needed for performing hardware level debugging, including:
    • Hardware adapter features
    • Target CPU features
    • TAP/DAP parameters
  • These files can become very complex
    • If you can, base yours off of an existing CPU
    • Grep for your CPU id in /usr/local/share/openocd/scripts/

OpenOCD: Config Files

  • Adapter
    • bcm2835gpio - This specifies the GPIO of the Pi
    • bcm2835gpio_jtag_nums 25 24 23 22 - Specify GPIO pins used
  • Transport mode (JTAG,SWD,etc)
    • transport select jtag
  • Adapter speed
    • adapter speed XXX
  • Tap settings
    • jtag newtap -irlen X -ircapture X -expected-id X
  • Reset Configuration
    • reset_config trst_only

OpenOCD: Example Config

source [find target/swj-dp.tcl]
# This is using the name on the SoC
if { [info exists CHIPNAME] } {
  set _CHIPNAME $CHIPNAME
} else {
  set _CHIPNAME s4ln045x01
}
# This is the TAP ID that we discovered in the previous step
if { [info exists CPUTAPID] } {
  set _CPUTAPID $CPUTAPID
} else {
  set _CPUTAPID 0x4ba00477
}
# Set the speed of our adapter
adapter_khz 200
# We are indeed using JTAG
transport select jtag
# We don't have a SRST pin, only TRST it would seem
reset_config trst_only
# Here we create the JTAG TAP/DAP, defining the location and characteristics of our DAP
swj_newdap $_CHIPNAME cpu -irlen 4 -ircapture 0x1 -irmask 0xf -expected-id $_CPUTAPID
dap create $_CHIPNAME.dap -chain-position $_CHIPNAME.cpu
target create $_TARGETNAME.1 cortex_r4 -endian $_ENDIAN -dap $_CHIPNAME.dap
set _TARGETNAME $_CHIPNAME.cpu

OpenOCD: Commands

  • md[b/h/w] address count - Memory display byte/halfword/word
  • halt - Halt the CPU (this is needed in order to read mem)
  • step - step to the next instruction
  • info reg - Display the current register state

OpenOCD: TAPs and DAPs

  • When using JTAG with OpenOCD a TAP must be defined to communicate with
    • jtag newtap ...
    • target create ...
  • SWD requires that a DAP be defined
    • swj_newdap ...
    • dap create ...
    • target create ...
  • Targets must be provided one of the following arguments to ensure they use the properly DAP/TAP
    • -chain-position POSITON_NUM - When using JTAG
    • -dap DAP_NAME - When using SWD

  • If possible, search through the available scripts for any information about your CPU
