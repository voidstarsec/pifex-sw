URJTAG

  • UrJTAG is a tool that allows for low level interraction with JTAG controllers
    • Developed to assist with boundary scans and SVF replays

  • Originally developed to replace closed source JTAG software

  • Advanced debugging can be achieved with UrJTAG by writing scripts and custom commands

  • Supports multiple hardware interfaces
    • FT2232H
    • JLink
    • Pi!

UrJTAG: Usage

  • Launch UrJTAG from the commandline via: sudo jtag

  • Define your cable: cable gpio tms=XX tck=X tdo=X tdi=X

  • Use the detect command to enumerate the scan chain!
    • detect
  • Use the discover command to autodetect IR and DR values!
    • discover
jtag> detect
IR length: 4
Chain length: 1
Device Id: 00010000000001000011010010110001 (0x100434B1)
  Unknown manufacturer! (01001011000) (/usr/local/share/urjtag/MANUFACTURERS)

UrJtag: Defining Registers

  • Registers can be defined as follows:
    • register NAME SIZE
  • Defining a 32 bit register for the IDCODE:
    • register ID_REG 32
  • Each instruction must have a register associated with it
    • Remember IR values are essentially used to select DRs

UrJtag: Defining Instructions

  • Instructions can be defined as follows:
    • instruction NAME VAL DATA_REG
  • Before defining instructions, the instruction length must be specified
    • instruction length 4
  • Defining the IDCODE instruction for our target:
    • instruction ID 1100 ID_REG

UrJTAG: State Machine Navigation

  • The JTAG state machine can be manually navigated using UrJTAG

  • Load an instruction:
    • instruction ID
  • Shift the instruction into the IR:
    • shift ir
  • Shift the value out of the data register
    • shift dr
  • Print out the shifted value:
    • dr
jtag> instruction ID
jtag> shift ir
jtag> dr
00000000000000000000000000000000 (0x00000000)
jtag> shift dr
jtag> dr
00010000000001000011010010110001 (0x100434B1)
