Rapsberry Pi Control Panel

Welcome to the Hardware Hacking and Exploitation Bootcamp!

This web interface will provide you with the necessary materials and information to perform the labs and follow along with the instructor presentation

Navigation

On the left, you will see the following drop down menus

Accessibility - Contains links to various utilities that will help you access the Pi materials including a file browser, terminal, and hex editor

Slides and Documentation - contains links to the relative slides as well as supplementary materials for those secions, use these to follow along with the instructor!

Lab Materials - contains relevant lab notes, commands, and links to other documentation and information that will help you solve the lab exercises

Tools - contains links to various tools, and instructions on how to use them throughout this course.

Pi Services / Credentials

  • The default user is pi with the password pihacking
  • An ssh server is running with the username: pi password: pihacking
  • An ftp server is running on port 21, and can be accessed with the standard user credentials

Directory Structure

The root directory of your Pi is laid out as follows:

  • tools - Contains relevant tools that you will use throughout this course
  • labs - Contains all of the lab materials for the various protocols in use
  • documentation - Assorted documents, relevant specifications, etc
